Task Performance Speed Algorithm

Automated scoring mapped from system constraints without manual story point entries.

The Core Formula

finalScore = basePoint × priorityMultiplier × typeMultiplier × statusMultiplier

Base Point

  • Calculated via date ranges.
  • Min: 1 point (1 day)
  • Max: 7 points (≥7 days)

Priority Multiplier

  • Weights business impacts.
  • Ranges from 0.8 to 2.0
  • Standard baseline: Low (1.0)

Type Multiplier

  • Reflects technical debt & size.
  • Ranges from 0.8 to 2.0
  • Subtasks scale down execution metrics.

Status Multiplier

  • Applies lifecycle outcome.
  • In-progress states = 0
  • Done/Confirm = 1.0 full credit
